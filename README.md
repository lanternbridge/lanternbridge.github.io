# Lantern Bridge

> The trusted bridge between Indonesia and China.

Multi-page Astro site for [lanternbridge.github.io](https://lanternbridge.github.io).

## Deployment

Every push to `main` triggers a GitHub Action that builds the site and publishes it to GitHub Pages. See `.github/workflows/deploy.yml`.

## Content

Most content lives in `src/data/`:

- `services.js` — the four service offerings
- `team.js` — founders and bios
- `testimonials.js` — client quotes
- `proof.js` — universities and industrial hubs
- `process.js` — the four-step workflow
